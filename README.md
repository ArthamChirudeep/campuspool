# Smart Campus Rides

Build CampusPool: a full-stack smart campus mobility and carpooling platform featuring deterministic smart route and timing matching, interactive map route visualizations with robust fallback, multi-step ride offering with recurring commute schedules, complete ride request and acceptance lifecycle, realtime ride chat, personal and SDG 11 sustainability impact dashboards, and an interactive competition demo mode with realistic campus seed data.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://campuspool.lovable.app
